# GreatOSS

Experiments in building useful open-source software with autonomous coding agents.

We gave four maintainers separate Ubuntu VMs, the same PDF-product mission, browser and desktop tools, and an individual $100 API-equivalent usage budget. Each chose a product name and built its own application. The final runs are complete; their code and websites are public.
